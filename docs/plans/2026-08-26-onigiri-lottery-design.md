# おにぎり抽選シミュレータ 設計書

作成日: 2026-08-26(改訂: 同日 新抽選仕様対応)
ステータス: 承認済み

## 1. 概要

おにぎりの具×味付けの組み合わせを抽選するSPA。iPhone 16 Safari での利用を前提とする。

- フロントエンドのみ(バックエンド/API なし)
- データ保存は localStorage
- 静的ホスティング(GitHub Pages 等)でデプロイ、URL 経由で利用

## 2. 確定した要件

| 項目 | 決定 |
|---|---|
| 抽選対象 | 1回の抽選で 具×味付け を **5組** 生成。各組は独立に抽選(同じ具・味付けが重複出現あり)。具・味付けそれぞれ均等確率 |
| 履歴 | 抽選セット(5組)を保存、**直近5セット**のみ保持。超えたら古い順に削除 |
| 具・味付けリスト | 初期リストあり + 追加/削除/編集可能。具リストは最低1件必須(全削除不可) |
| 技術 | Vite + React 18 + TS(Vitest/TDD)、状態管理ライブラリなし |
| 場所 | D:\ドキュメント\DEV\onigiri-lottery |
| UI | ミニマル・薄い水色ベース・AI臭なし |

## 3. アーキテクチャ

- Vite + React + TypeScript + Vitest。
- 依存は React のみ(ルーティング/状態管理ライブラリなし)。3画面はタブ state 切替。
- ロジック層(純関数)・ストレージ層と UI を分離し、テスト容易性を確保。

```
src/
  domain/       # 純関数: 抽選、データ正規化
  storage/      # localStorage 読み書き・検証
  hooks/        # useAppState(状態 + 永続化の窓口)
  components/   # Presentational components(TabBar 等)
  screens/      # 抽選 / リスト管理 / 履歴
  App.tsx       # タブ切替
```

## 4. データ設計

具・味付けは単純な `string[]`(UUID 等は持たない — YAGNI)。

```
key: onigiri-lottery
{
  "fillings":   ["鮭", "梅", "おかか", "昆布", "ツナマヨ", "明太子", "焼きたらこ", "たまご"],
  "seasonings": ["塩", "醤油", "ごま油", "なし"],
  "history": [
    {
      "results": [
        { "filling": "鮭", "seasoning": "塩" },
        ... 5組
      ],
      "at": 1756200000000
    }
  ]
}
```

- 読み込み時にスキーマ検証。不正データは初期値へフォールバック(部分欠損はマージ)。
- history の各セットは results が5件の有効ペアであることを検証し、不正なセットは除外。保持は5セット上限。
- localStorage 無効環境(プライベートモード等)はメモリのみで動作し警告表示。

## 5. 抽選ロジック(domain/lottery.ts)

- `drawOne(items: string[]): string | null` — 均等確率で1件。空リストは null。
- `drawSet(fillings: string[], seasonings: string[], count = 5): LotteryResult[] | null`
  - fillings が空なら null。seasonings が空なら味付けなし(空文字)として扱う。
  - count 組、各組独立に 具と味付けを抽選。

## 6. 画面構成(下部タブ3画面)

1. **抽選画面**
   - 「まわす」ボタン → 5組を一括抽選 → 結果を5行で表示(簡易アニメーション CSS のみ)
   - 具が0件の場合はボタン無効 + 案内(仕様上起こり得ないが防御)
2. **リスト管理画面**
   - 具 / 味付けをセグメント切替
   - 追加(テキスト入力)・削除(確認)・編集(インライン)
   - 空・重複・最大20文字のバリデーション
   - 具は最後の1件を削除不可
3. **履歴画面**
   - セット単位で最新順表示(5セットまで)
   - 履歴クリア(全削除、確認ダイアログ)

## 7. UI方針

- 薄い水色ベース(#EAF4F8 系)、システムフォント準拠、ミニマル
- safe-area 対応(`env(safe-area-inset-bottom)`)、`100dvh`、タップターゲット44px以上

- 抽選純関数: 均等性(簡易分布検定)・0件・1件・5組生成・独立性
- モデル正規化: 不正JSON・部分欠損・historyセット検証・5セット上限
- ストレージ層: 保存/読込/不正JSON/空localStorage/初期値マージ
- フック: 操作→localStorage 保存・履歴5セット上限
- コンポーネント: まわす→5組表示、リストCRUDバリデーション、履歴表示・クリア
