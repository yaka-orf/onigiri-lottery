# おにシミュ Phase 3 設計書(作成モード・タグ管理再編)

日付: 2026-08-27
ステータス: 承認済み(ユーザー回答済み)

## 変更一覧

### F1: タグ管理を「タグ」ジャンルへ移動
- 管理タブのセグメント(具/味付け)に「タグ」を追加(3ボタン目)
- タグ選択時: item-list形式でタグ一覧表示(具と同じUI)
  - 各行: タグ名 + 編集/削除ボタン(drag-handleなし・並べ替え不要)
  - 除外ボタン・カテゴリセレクトは非表示
- 既存の tag-section(具タブ内の専用セクション)は削除
- 追加行(placeholder「新しいタグを追加」+追加ボタン)は下部にそのまま

### F2: サウンドボタン絵文字除去
- 「🔊 サウンド ON」→「サウンド ON」、「🔇 サウンド OFF」→「サウンド OFF」

### F3: タブラベル変更
- 「抽選」→「作成」
- 「おにる！」→「ランダムでおにる」

### F4: 手動組み合わせモード「自分でおにる」
- 作成タブ内に「ランダム/自分」モードトグル(既存の具1つ/具2つトグルと同じUI・上位に配置)
- 「自分」モードUI:
  - 個数ステッパー(1〜10)は共有(ランダムと同じstate.settings.count)
  - count行のセレクト: 1具=具セレクト+味付けセレクト / 2具=具1+具2+味付けセレクト
  - セレクトの選択肢は effectiveFillings/effectiveSeasonings(カテゴリ絞り込み・除外を反映)
  - 2具は同一具不可(引いた時点でバリデーション、選択は自由・確定時チェック)
  - 下部「自分でおにる」ボタン → 履歴に記録 + 結果表示(アニメーションなし or あり→ありで統一)
- モード切替時: 手動の選択内容はリセット(単純化。永続化しない)

### F5: ランダム結果を手動モードへ引き継ぎ編集
- ランダム結果表示部に「編集」ボタン追加
- タップ → モードを「自分」に切替 + ランダム結果をセレクトに引き継ぎ
- 編集後「自分でおにる」で確定 → 履歴記録(ランダム時の記録とは別エントリ)

### 画面構成(作成タブ)

```
[ランダム | 自分]          ← 新モードトグル
[全部|肉|魚介|定番|その他]   ← カテゴリチップ(ランダム時のみ)
[具1つ | 具2つ]            ← 既存トグル
[- 5個 +]                 ← 個数ステッパー
(ランダム時) [ランダムでおにる]
(自分時)   セレクト行×count
           [自分でおにる]
結果表示
[結果をコピー] [編集]       ← 編集はランダム結果表示時
```

## データモデル変更
