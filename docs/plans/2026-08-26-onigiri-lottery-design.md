# おにぎり抽選シミュレータ 設計書

作成日: 2026-08-26
ステータス: 承認済み

## 1. 概要

おにぎりの具を抽選し、味付けを手動選択するSPA。iPhone 16 Safari での利用を前提とする。

- フロントエンドのみ(バックエンド/API なし)
- データ保存は localStorage
- 静的ホスティング(GitHub Pages 等)でデプロイ、URL 経由で利用

## 2. 確定した要件

| 項目 | 決定 |
|---|---|
| 抽選対象 | 具のみ抽選(均等確率)、味付けは手動選択 |
| 履歴 | 具×味付けのセットを保存、直近のみ表示 |
| 具・味付けリスト | 初期リストあり + 追加/削除/編集可能 |
| 技術 | Vite + React + TS、静的ホスティング |
| 場所 | D:\ドキュメント\DEV\onigiri-lottery |
| テスト | Vitest + TDD |
| UI | ミニマル・薄い水色ベース・AI臭なし |

## 3. アーキテクチャ

- Vite + React + TypeScript + Vitest。
- 依存は React のみ追加(ルーティング/状態管理ライブラリなし)。3画面はタブ state 切替。
- ロジック層(純関数・ストレージ層)と UI を分離し、テスト容易性を確保。

```
src/
  domain/       # 純関数:抽選、データ正規化
  storage/      # localStorage 読み書き・検証
  hooks/        # useFillings / useSeasonings / useHistory
  components/   # Presentational components
  screens/      # 抽選 / リスト管理 / 履歴
  App.tsx       # タブ切替 + 永続化の窓口
```

## 4. 画面構成(下部タブ3画面)

1. **抽選画面**
   - 「まわす」ボタン → 具を均等抽選 → 結果表示(簡易スロット風アニメーション、CSSのみ)
   - 味付けをチップ/セグメントで選択 → 「決定」で履歴保存
   - 具が0件の場合はボタン無効+案内
2. **リスト管理画面**
   - 具 / 味付けをセグメント切替
   - 追加(テキスト入力)・削除(確認ダイアログ)・編集(インライン)
   - 空・重複・最大長のバリデーション
3. **履歴画面**
   - 最新順、最新N件表示 + 「もっと見る」
   - 履歴クリア(全削除、確認ダイアログ)

## 5. データ設計(localStorage)

```
key: onigiri-lottery
{
  "fillings":   ["鮭", "梅", "おかか", ...],
  "seasonings": ["塩", "醤油", "味噌", ...],
  "history": [
    { "filling": "鮭", "seasoning": "塩", "at": 1756200000000 }
  ]
}
```

- 読み込み時にスキーマ検証。不正データは初期値へフォールバック。
- localStorage 無効環境(プライベートモード等)はメモリのみで動作し警告表示。

## 6. 抽選ロジック

- 純関数 `drawLottery(items: string[]): string | null` — 均等確率。
- 具0件時は null を返し UI 側で案内。

## 7. UI方針

- 薄い水色ベース(例: #EAF4F8 系)、システムフォント準拠、ミニマル
- safe-area 対応(`env(safe-area-inset-bottom)`)、`100dvh`、タップターゲット44px以上
- AI臭のない素朴な配色・文面

## 8. テスト戦略(Vitest + TDD)

- 抽選純関数: 均等性(簡易分布検定)・0件・1件
- ストレージ層: 保存/読込/不正JSON/空localStorage/初期値マージ
- コンポーネント: 抽選→味付け→決定フローを重視
